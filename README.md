# Admin Dashboard

A modern and responsive Admin Dashboard built with React. The dashboard provides an intuitive interface for managing projects, viewing announcements, tracking trends, and monitoring user activity.

## 🚀 Live Demo

https://admin-ruddy-xi-43.vercel.app/

## 📸 Features

- Responsive Dashboard Layout
- User Profile Section
- Project Management Overview
- Announcements Panel
- Trending Updates Section
- Search Functionality
- Modern UI Design
- Reusable Components
- Mobile-Friendly Design
